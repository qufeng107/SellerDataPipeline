# ADR-007: Manual-first Before Automation

> 状态：Accepted  
> 日期：2026-05-18

## Context

SellerDataPipeline 已经完成核心数据的手动 ingestion 闭环。下一步有两条可能路径：

1. 直接开发 Azure Container Apps Jobs 自动化调度。
2. 先把所有业务能力做成可手动执行、可复核、可审计的 CLI 流程，再迁移到自动化。

利润核算、周报、邮件发送等功能涉及财务口径和业务判断，直接自动化风险较高。

## Decision

采用 manual-first 策略：

```text
先手动可执行
再手动可复核
再半自动生成草稿
最后自动化调度与告警
```

自动化 Jobs 不重新设计业务逻辑，只复用已经通过手动验收的 CLI、配置、数据库表和审计机制。

## Consequences

正面影响：

1. 降低早期自动化把错误放大的风险。
2. 保持每个步骤可观察、可复查、可回滚。
3. 让利润核算和周报口径先经过人工确认。
4. 未来自动化 Jobs 更容易实现，因为输入、输出和验收已经固定。

代价：

1. 前期仍需要人工运行脚本。
2. 文档和 runbook 需要维护得更清楚。
3. 需要在数据库中记录任务 cadence，避免人工流程和未来自动化脱节。
